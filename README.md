## Linux automatisches Tools-Update
 
````bash
wget https://github.com/TheoRichter/SVWS-Tools/raw/refs/heads/main/downloads/tools-update_linux.zip
unzip tools-update_linux.zip
bash tools-update_linux.sh
````

## Windows automatisches Tools-Update

 [Download von **Tools-Update_Windows.zip**](https://github.com/TheoRichter/SVWS-Tools/raw/refs/heads/main/downloads/tools-update_windows.zip)  

Die Datei **tools-update_windows.zip** entpacken und als Administrator starten. 

![Administartor](graphics/tools-update_windows.png)


## Vorwort

Um die SVWS-Tools nutzen zu können, müß der [SVWS-Server](https://github.com/SVWS-NRW/SVWS-Server/releases) **local** auf dem PC installiert sein.

Bei Linux muß eine Desktop installation vorliegen.
