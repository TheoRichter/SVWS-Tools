# Installation der SVWS-Tools für den SVWS-Server 

## Einbinden der SVWS-Tools Conference, Gradehub, Import, Laufbahnplanung und Prognos

## Vorwort

Um die SVWS-Tools nutzen zu können, müß der [SVWS-Server](https://github.com/SVWS-NRW/SVWS-Server/releases) local auf dem PC installiert sei.

Bei Linux muß eine Desktop installiert vorliegen.

**Hinweis:** 

*Ich benutze nicht das offizielle [SVWS-Tools](https://github.com/SVWS-NRW/SVWS-Tools/releases)!*
